Format on save

Change Color Theme
- Setting -> Theme -> Color Theme

AUTO SAVE
- at the top Go to File -> Auto Save - check it

SPLIT SCREEN
- View -> screen Layout - split up/down

Word Wrap
- Setting -> word wrap -> turn on
- View -> word wrap - check it - temporary

Bracket pair Colorized
-  its built in
- Settings -> Search bracket -> change Editor Guides: Bracket Pairs to <span style="color:rgb(146, 208, 80)"><span style="color:rgb(146, 208, 80)">true/active</span></span>
Compact Folder
- Settings -> uncheck Compact Folders
- list of folders
Preview (if a new tab should open when opening another file)
- Settings -> uncheck Work bench > editor: Enable Preview

```json
{
"editor.formatOnSave": true,
"files.autoSave": "afterDelay",
"workbench.iconTheme": "material-icon-theme",
"workbench.colorTheme": "Visual Studio Dark",
"editor.wordWrap": "on",
"editor.defaultFormatter": "esbenp.prettier-vscode",
"editor.formatOnPaste": true,
"editor.guides.bracketPairs": true,
"explorer.compactFolders": false,
"workbench.editor.enablePreview": false
}
```
