# responsive website: what is media query?
The problem
- as people are using websites in different devices, a single design might not look best in all size devices. 
- the ideal solution is to have different designs for different sizes.




The solution:
- CSS media query

# The mobile first development approach
- it means write all your CSS code in a way it works for mobile by default, without media queries.
- Then use media queries to implement design bigger screens from mobile screens.
