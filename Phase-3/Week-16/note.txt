MAIN CATEGORIES OF DB

1. Relational DB
2. NoSQL DATABASE

1. Relational DB
- stores and provides access to data points that are related to one another.
Eg of DB system that use this mode: MS SQL server, Oracle DB and MySQL

Relational Model
- has multiple tables, tabular method
- tables are structures relating to each other
- has primary key => foreign key

normalization: organizing a relational database to minimize data redundancy and prevent data anomalies. 
- It involves splitting large, messy tables into smaller, logical tables and defining relationships between them.

2. NoSQL DB
- have documents with objects inside them
- mostly key + value pair => like json
Eg. MongoDB
- when querying its straightforward, simple

3.1 HTTP verbs
HTTP defines a set of request methods to indicate the desired action to be performed for a given resource.

        * GET
                -  read some data and receive it      

        * POST
                -  i have new data that i need to be written or creating new data

        * PUT AND PATCH
                - are for updating
           PUT 
                - Replaces the entire data with a new representation in a single tables
                - client sends the entire updated representation of the resource to the server 

           PATCH  
                - partially updates the data
                - client sends only the specific changes to be applied to the resource

        * DELETE
        - means, i need to remove some data
